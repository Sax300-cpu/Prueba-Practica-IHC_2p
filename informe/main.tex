\section{Informe de guía práctica}
\subsection{Objetivos}
\subsubsection{General}
Diseñar, implementar, evaluar y validar una aplicación web interactiva para la cafetería universitaria CaféU 2.0, integrando experiencia de usuario, arquitectura de información, prototipado, accesibilidad, ingeniería de software y métodos de evaluación de usabilidad.

\subsubsection{Específicos}
\begin{itemize}
    \item Analizar a la persona usuaria y su recorrido, relacionando los problemas detectados con los principios de Nielsen y Gestalt.
    \item Definir requisitos, sitemap, user flow y wireframes, y mantener su trazabilidad con las pantallas y las pruebas.
    \item Implementar catálogo, búsqueda tolerante a tildes y mayúsculas, carrito, cantidades, eliminación y confirmación, separando presentación, aplicación, dominio e infraestructura.
    \item Planificar y ejecutar la evaluación de usabilidad (heurística, recorrido cognitivo, accesibilidad y pruebas con usuarios).
    \item Triangular los resultados, priorizar el backlog, corregir al menos dos problemas y validar la versión v2.
\end{itemize}
